# Little by Little｜家庭陪伴小站

这是可以直接发布到 GitHub Pages 的静态网站，无须服务器、安装或构建。

## 发布步骤（推荐新建一个仓库）
1. 在 GitHub 创建一个新仓库，例如 `little-by-little`。
2. 解压本 ZIP，把 `index.html`、`assets` 文件夹内所有文件等上传到仓库根目录（不要只上传 ZIP）。
3. 打开仓库 Settings → Pages → Build and deployment → Source 选择 Deploy from a branch。
4. Branch 选择 main、文件夹 /(root)，点击 Save。部署完成后从 Pages 页面复制链接发给家人。
5. 以后更新网页，只需要覆盖相关文件。不要删除仓库。

## 手机使用
在 Safari/Chrome 打开网址；iPhone 可通过 Safari 的分享菜单“添加到主屏幕”；Android 可通过浏览器菜单添加到主屏幕。

## 特别注意
- GitHub Pages 网站通常是公开访问的；带孩子插画的版本不适合需要严格隐私的场景。若不想公开孩子形象，发布无人物图的隐私版。
- 打卡、生日、成长观察仅保存在各自设备的浏览器，不会在不同家人之间同步，也不会上传到 GitHub。
- 清理浏览器数据、换设备或使用无痕模式可能导致记录消失。可在“成长足迹”使用导出记录功能备份；目前没有导入或家人共享编辑。
- 一周内容根据设备本地日期和月龄分层生成，属于家长参考活动，不构成医疗或发育诊断。
- 图片属于家庭私人素材，避免用于商业宣传或公开传播。
